# 桌面端+ngrok+手机App联动配置教程（精简总结版）

## 一、现有设备与文件资源

1. **电脑桌面后台端**：安装包 `Xingye Sample Manager\-Setup\-1\.0\.0\.exe`

2. **ngrok工具**：路径 `C:\\ngrok\-v3\-stable\-windows\-amd64`

3. **安卓手机App**：需通过 HBuilderX 重新打包生成新 APK 安装使用

## 二、最终实现流程

电脑启动桌面后台 → 电脑运行 ngrok 映射端口 → 后台自动同步外网地址、生成二维码 → 手机打开新版App → 扫码自动配置服务器地址 → 正常登录使用

## 三、电脑桌面端安装启动

1. 找到安装包 `Xingye Sample Manager\-Setup\-1\.0\.0\.exe`，双击完成安装

2. 打开桌面快捷方式`Xingye Sample Manager`，进入后台首页

首页核心展示内容：移动端当前外网地址、配套二维码、APK下载地址、当前生效APK文件信息。

## 四、ngrok启动配置（核心步骤）

1. 进入 ngrok 所在文件夹，运行 `ngrok\.exe`

2. 执行命令将本机 **3000端口** 外网映射

3. 成功后生成全新的 `https://xxxx\.ngrok\-free\.dev` 外网地址

## 五、桌面端同步ngrok地址

1. ngrok启动后，返回后台首页，点击「立即刷新状态/重新扫描」自动同步地址

2. 自动同步失败：手动复制ngrok外网地址，在后台「手动填写服务器地址」处粘贴保存

3. 地址保存后，首页二维码会自动同步更新

## 六、手机端新版APK打包与安装

### 1\. 打包操作（移动端代码更新必做）

1. 打开 HBuilderX，通过「文件\-打开目录」导入项目：`C:\\Users\\surface\\Desktop\\Note\\apps\\miniprogram`

2. 顶部菜单选择「发行\-原生App\-云打包/本地打包」，选择Android平台完成打包，获取新APK

### 2\. 安装方式

- 方式1：电脑后台复制APK下载地址，手机浏览器打开下载安装

- 方式2：手动将打包好的APK传输至手机，允许未知来源应用后安装

### 3\. 版本校验

安装完成后，登录页显示「扫码配置」「服务器设置」入口，即为新版；无对应入口则为旧版本，需重新安装。

## 七、手机端扫码配置流程

1. 打开新版App，进入登录页，点击「扫码配置」

2. 首次使用允许相机权限，对准电脑后台二维码扫描

3. 扫码成功自动写入服务器地址，提示写入成功

4. 校验方式：登录页查看当前服务器地址 / 进入「服务器设置」查看生效地址

## 八、日常使用规则

### 1\. 地址变更处理

ngrok重启后外网地址更新：无需重打包APK，手机重新扫码配置即可。

### 2\. 代码变更处理

移动端代码修改后：必须重新打包、安装新版APK。

## 九、常见问题排查

### 1\. 扫码无法写入地址

依次排查：是否为新版APK、是否开启相机权限、后台地址与二维码是否匹配、ngrok进程是否正常运行、是否残留旧服务器地址。

兜底方案：后台复制最新外网地址，手机端进入「服务器设置」手动粘贴保存。

### 2\. 后台二维码地址错误

核对后台「移动端当前地址」是否为最新ngrok地址，不一致则刷新页面或手动填写正确地址，二维码将自动同步。

## 十、日常标准操作流程

1. 打开电脑桌面后台端

2. 启动本地后台、运行ngrok端口映射

3. 确认后台同步最新外网地址与二维码

4. 手机App扫码配置新地址，登录使用

## 十一、一句话核心口诀

电脑开后台、启ngrok，手机扫码配地址，即可正常使用；**地址变仅重扫码，代码变必重打包**。
