# JNRon 移动端使用教程

## 1. 适用对象

本教程适用于 Android App 用户，常见角色包括：

- 操作员：认领项目、开始工序、完成工序。
- 检测员：查看待处理工序、上传检测报告、查看历史报告。
- 只读查看：查看项目整体进度，不做修改。
- 管理员：除以上能力外，还可以在移动端新建和删除样品。

## 2. 使用前准备

1. 在手机上安装 JNRon Android App。
2. 向管理员获取账号和密码。
3. 确认桌面端后台已经启动，并且管理员已经配置好可访问的服务器地址。
4. 如果是首次使用，建议先让管理员提供“服务器配置二维码”。

## 3. 登录

1. 打开 App，进入“账号登录”页面。
2. 查看页面顶部显示的当前服务器地址。
3. 输入账号和密码，点击“进入工作台”。
4. 如果登录成功，系统会根据角色进入任务页。

### 登录失败时怎么处理

如果提示无法连接服务器，通常有以下几种原因：

- 当前服务器地址不对。
- 桌面端服务没有启动。
- 手机与服务器网络不通。

这时可以点击登录页里的“服务器配置”，重新写入最新地址。

## 4. 服务器配置

服务器配置页用于给 App 写入正确的后台地址。

### 方法一：扫描服务器二维码

1. 进入“服务器配置”页面。
2. 点击“扫描配置服务器”。
3. 扫描管理员在后台设置页展示的“服务器配置二维码”。
4. 识别成功后，地址会自动保存并返回上一页。

### 方法二：从相册识别二维码

1. 进入“服务器配置”页面。
2. 点击“从相册识别二维码”。
3. 选择管理员发来的服务器二维码图片。
4. 识别成功后，地址会自动保存。

### 方法三：手动输入地址

1. 在“服务器地址”输入框中填写完整地址，例如 `https://xxxx.cpolar.top`。
2. 点击“保存并返回”。

### 其他按钮说明

- 恢复默认：将地址恢复到应用内置默认值。
- 当前生效：显示 App 现在真正使用的后台地址。

## 5. 任务页的基本用法

登录后默认进入“任务”页，不同角色看到的内容不同。

### 操作员

操作员常见视图包括：

- 待认领项目：还没有操作员接手的项目。
- 我的项目：已经由自己认领或正在处理的项目。
- 已完成项目：全部工序已经完成的项目。

#### 操作步骤

1. 在任务列表中点开项目。
2. 点击某一道待开始工序进入详情。
3. 点击“开始并认领项目”或“开始工序”。
4. 工序处理完成后，点击“完成工序”。

说明：

- 第一次开始工序时，系统会自动把整个项目认领给当前操作员。
- 已经被其他操作员认领的项目，当前账号不能继续处理。

### 检测员

检测员常见视图包括：

- 待上传报告：操作员已完成，但还没有检测报告的工序。
- 已上传报告：已经上传过检测报告的工序。

#### 操作步骤

1. 进入“待上传报告”。
2. 点开工序详情。
3. 在“操作”区域点击“上传检测报告”。
4. 选择拍照或从本地相册选择图片。
5. 上传完成后，可在“检测报告”列表里查看、分享或删除。

说明：

- 只有工序已经完成后，检测员才能上传检测报告。
- 如果项目已经绑定检测员，通常只有该检测员本人可以继续上传和维护报告。

### 只读查看

只读账号可查看：

- 项目整体进度。
- 各工序状态。
- 图纸附件。
- 工序执行人与最新检测员。

只读账号不能开始工序、完成工序或上传报告。

## 6. 项目详情与工序详情

### 项目详情页可以看什么

- 样品编号、项目名称、材料、客户信息。
- 项目操作员与项目检测员。
- 图纸数量与工序数量。
- 工序流程和整体完成度。
- 项目图纸附件。

### 工序详情页可以看什么

- 当前工序状态。
- 开始时间、完成时间。
- 报告存储路径。
- 已上传的检测报告列表。
- 当前角色可执行的按钮。

## 7. 我的页面

“我的”页面里通常可以完成以下操作：

- 查看账号、角色和当前服务器地址。
- 查看个人任务统计。
- 返回任务列表或历史记录。
- 打开服务器配置页。
- 打开应用更新页。
- 管理员进入移动端样品管理。
- 退出登录。

## 8. 应用更新

移动端更新页支持两种方式。

### 方式一：检查当前服务器分发版本

1. 进入“我的”。
2. 点击“应用更新”。
3. 查看本机版本和服务端安装包信息。
4. 点击“检查当前版本”刷新。
5. 点击“下载并安装”开始更新。

### 方式二：扫描更新二维码

1. 进入“应用更新”。
2. 点击“扫描更新二维码”。
3. 扫描管理员后台提供的“移动端下载二维码”。
4. 系统识别到指定版本后，会提示是否立即下载安装。

也可以点击“从相册识别二维码”，识别管理员发来的二维码图片。

### 更新时的注意事项

- 该功能仅支持 Android App 内更新。
- 安装时会弹出系统安装界面。
- 如果系统提示“未知来源安装”，请按系统提示授权当前应用继续安装。

## 9. 管理员在移动端可做的额外操作

管理员除了普通查看能力，还可以在“样品管理”页面：

- 新建样品。
- 填写项目名称、样品编号、报告路径、客户、材料等信息。
- 增加工序。
- 删除样品。

建议正式批量维护时仍以后台网页端为主，移动端更适合临时补录和现场处理。

## 10. 常见问题

### 1）扫了二维码还是连不上

- 先确认桌面端服务正在运行。
- 再确认管理员提供的是最新二维码。
- 如果管理员更换了公网地址，需要重新扫码。

### 2）看不到待处理任务

- 先确认账号角色是否正确。
- 再确认项目是否已经分配或已进入当前角色可见状态。
- 只读账号只能查看，不会出现处理按钮。

### 3）无法上传检测报告

- 只有已完成的工序才支持上传。
- 当前账号需要具备检测员权限，或管理员权限。
- 请检查相机/相册权限是否已授权。

### 4）无法安装更新包

- 请确认当前设备是 Android。
- 请确认系统允许安装应用更新包。
- 如果下载二维码失效，请让管理员重新在后台切换或上传版本后再试。

## 11. 推荐使用顺序

1. 先扫码完成服务器配置。
2. 再登录账号。
3. 根据角色进入任务处理。
4. 需要时在“我的”里检查应用更新。
5. 如果管理员通知切换新版，可直接扫下载二维码完成升级。
