Quick Start

1. 登录与服务器配置

首次使用建议先完成服务器配置，再输入账号密码登录。登录页和“我的”页都能进入服务器配置。

02Mobile

使用前准备

  • 管理员已启动桌面端后台服务。
  • 手机已安装 JNRon Android App。
  • 已获取账号密码，以及最新服务器二维码。

登录步骤

1
确认当前服务器地址 登录页会显示当前后台地址，地址错误时先不要继续输入密码。
2
输入账号与密码 点击“进入工作台”后，系统会自动跳到对应角色的任务页。
3
连接失败时打开服务器配置 优先扫码写入最新地址，其次再手动输入公网地址。

服务器配置推荐顺序

1
扫描服务器二维码 最快，适合现场分发。
2
从相册识别二维码 适合管理员通过微信发送二维码图片。
3
手动输入完整地址 例如 `https://demo.cpolar.top`，不要自行追加 `/api`。

操作员流程

  • 从“待认领项目”进入第一道待开始工序。
  • 点击“开始并认领项目”后，项目会自动归属给当前操作员。
  • 处理完成后点击“完成工序”，再进入下一道工序。
  • 如果项目已被别人认领，当前账号不能继续接手。

检测员流程

  • 从“待上传报告”进入已完成的工序。
  • 点击“上传检测报告”，支持拍照或从相册选图。
  • 上传后可查看、分享或删除报告附件。
  • 通常只有项目绑定的检测员本人可以继续维护报告。

常见问题

  • 扫码后仍无法连接：先确认桌面端服务已启动，再让管理员重新发送最新地址二维码。
  • 看不到任务：先核对账号角色，再检查项目是否已进入当前角色可见状态。
  • 不能上传报告：只有已完成工序才允许上传，且当前账号需要检测员或管理员权限。
  • 无法安装更新：确认设备为 Android，并按系统提示允许当前应用继续安装。
